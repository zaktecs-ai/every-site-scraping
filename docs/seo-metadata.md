## Extended description (for websites, listings, and registries)

GitHub caps the repository description at 350 characters, so the full approved description lives here for surfaces without that limit:

Every-Site Scraping is a Python 3.8+ command-line tool that scrapes an arbitrary list of URLs in parallel (10 workers by default, configurable) and writes one CSV row per site across a fixed 90-column schema. Each row captures identity, Open Graph and Twitter cards, SEO fields, content structure, links and asset URLs, social profiles, contact details, JSON-LD organization data, tech stack, and page weight. Input can be plain URLs, a TXT file, or a CSV with an auto-detected website column. Outputs include CSV, typed JSON, a JSONL log, and a run summary. Every row is flushed to disk as it completes, so runs survive crashes and continue with --resume. Built on requests, BeautifulSoup, and lxml; MIT licensed and covered by 68 unit tests.
